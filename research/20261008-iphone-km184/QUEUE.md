## Phase 1 — 데이터 정합성 확인 [진행 중]
완료 기준: 전체 구간의 정렬 오차와 데이터 결함을 수치로 관리.
- [x] 샘플레이트·채널·DC·디지털 클리핑 진단.
- [x] 고정 지연·선형 드리프트 1차 추정, 정렬 실패 구간 제외 기준 기록.
- [x] 사용자 주법/신호 라벨, 경계 후보와 불확실성, 구간 청취 파일 연결.
- [x] 라벨 밖 배경 후보 추출 및 대역별 배경 대비 레벨 계산 (`phase1_noise.py`). 이는 아직 확정 SNR이 아님.
- [ ] 배경 후보의 잔향·취급음·미라벨 신호 혼입 확인. 기타 두 장치 동시 저레벨 후보 9개와 후반 두 시기의 대역 변동은 계산했으나 청취 확인 및 초반/후반 잡음 정상성은 남음.
- [ ] 광대역 구간으로 폴라리티·지연 재검증; 주기적 기타 음에서 발생하는 상관 피크 모호성 관리.
- [ ] 신호별 정렬·클리핑·유효 대역 QC표 확정. 기존 전체 혼합 10초 블록을 신호별 QC로 대체.

## Phase 2 — 스윕 및 핑크노이즈 분석 [현재 자료 진단 완료; 순수 직접음 IR·전대역 기준 미확정]
완료 기준: 기본 상대 응답과 시간창별 불확실성 확인. [Phase 2 종합 페이지](../../docs/experiments/20261008-iphone-km184/phase2-synthesis.html)에 현재 판정과 원자료를 연결.
- [x] NAM v3 원본 세 chirp의 파형·레벨·자기상관·입력 대역 범위와 중간/높은 레벨의 조건부 디컨볼루션 비교 (`nam_chirp_source_qc.py`). 약 1/50/250배 파형 반복, 100Hz–16kHz 입력 대역 파워 범위 21.82dB, 200Hz–8kHz 중간/높은 레벨 응답 모양 차이 중앙 KM184 0.10dB/iPhone 0.43dB. 이는 짧은 NAM 보조 입력의 예비 진단이며 별도 스윕/직접음 IR 검증은 아님.
- [x] 두 번째 로그·세 번째 선형의 AudioCheck 출처 확인 및 MP3/OGG 파일 후보의 시간축·코덱별 차이 검사. BigSoundBank 44.1/48kHz 재생성 파일은 실제 재생 원본으로 취급하지 않음. **실제 재생 코덱·플레이백 체인과 무손실 원본은 미확인**.
- [x] AudioCheck MP3/OGG 로그·선형에 대해 iPhone/KM184 각각 정규화 디컨볼루션과 피크 기준 5/10/20/50/100ms 창의 조건부 응답·에너지 검사 (`audiocheck_ir_qc.py`). 50ms 로그–선형은 2–5kHz 차이 중앙 1.13dB이나 로그–노이즈는 5.61dB. −1~+50ms 에너지의 −1~+5ms 비율 KM184 27–35%, iPhone 24–26%; 늦은 성분은 반사와 코덱/정렬/역필터 퍼짐을 분리할 수 없음.
- [x] pink/white 파워비·H1·코히어런스 대역별 교차 진단 (`cross-signal-fr.json`, `phase2-synthesis.json`). 두 노이즈의 1–2kHz 정규화 모양 차이 중앙 0.22dB, 코히어런스 중앙 pink/white 0.81/0.78. 5–10kHz 코히어런스는 0.48/0.33으로 하락. 노이즈 파워비도 방을 포함.
- [x] 5/10/20/50ms 및 긴 창의 안정성-반사 포함량 교환관계를 수치로 표시. f≥2/창 길이의 진단적 저주파 하한은 5ms≈400Hz, 10ms≈200Hz, 20ms≈100Hz, 50ms≈40Hz이며 실제 유효 하한을 보증하는 규칙은 아님.
- [ ] 물리적 첫 도달, 초기 반사의 시간·방향, 왜곡/잡음과 선형 IR의 분리. 현재 피크는 코덱·원점·방 반응과 얽혀 있어 확정 불가. 동일 배치에서 재생 파일/코덱·출력 경로·동기 마커가 기록된 새 측정 필요.
- [ ] 승인된 전대역 스피커 기준 FIR. 기존 `reference-fir-v0.json`의 1025탭 1.05–2.3kHz 필터는 **진단용 부분 EQ**이고, 현 스윕 내 적합을 일반화하지 않음. 120Hz 기타 EQ는 별도의 경험적 설계.

## Phase 3 — 기타 구간별 보정 분석 [10월 현 자료 진단 완료; 정확한 사건 라벨·독립 세션 검증 미완료]
완료 기준: 주파수×구간 보정량·신뢰도 행렬 확보. [Phase 3 종합 페이지](../../docs/experiments/20261008-iphone-km184/phase3-synthesis.html)와 `phase3-window-manifest.json` 참조.
- [x] 15개 주법 라벨·3개 개방현 반복 묶음과 2초/5초 창의 모집단·제외 사유 고정 (`phase3_window_manifest.py`). 창은 원래 시각을 유지하며 무음을 잘라 이어 붙이지 않음. 5초 활동 대역 관측은 14주법 304창, 같은 EQ 조건 점수는 11주법 152창. 하모닉스·긴 화음·마지막 곡·초반 6→1번줄의 EQ 공백을 0으로 채우지 않음.
- [x] 11주법 152창에서 100.8/127/160Hz 및 1264.9/1593.1/2006Hz의 파워비·H1·코히어런스와 10dB 양쪽 배경 마스크 비교 (`phase3_h1_group_qc.py`). 저역 코히어런스 중앙 0.96–0.98, 중역 0.49–0.54. 서로 다른 음장과 비정상 기타 신호이므로 중역 H1을 마이크 고유 응답으로 해석하지 않음.
- [x] 기존 주법별 관측/정렬/반복/정규화 민감도 장부와 고정 필터 효과를 종합 (`phase3_synthesis.py`): 11주법 모두에서 저역 한 단의 저역 점수와 10월 FIR의 중역 점수 평균 개선. 주법 동일 가중 감소량 1.015/1.569dB. 퍼커션 저역은 개선이 작고 6창 중 3창 악화.
- [x] 고정 필터의 조건별 적용 범위를 기존 152창에서 주법 내부 순위로 비교 (`phase3_condition_sensitivity.py`). 녹음 RMS·50ms 엔벌로프 변화·100–160Hz 배경 여유의 각 3등분에서 120Hz 한 단의 저역 오차 감소는 약 0.93–1.10dB, 10월 FIR 중역 감소는 약 1.39–1.66dB. 모두 설계 노출 자료의 설명이며 음량·어택·음높이의 인과 효과가 아님.
- [x] 11주법 그룹 재표본 10,000회로 *같은 세션 악구 간* 평균 개선 민감도 계산. 저역 한 단 0.823–1.150dB, 10월 FIR 중역 1.441–1.700dB(95% 재표본 구간). 한 주법 한 연속 구간이므로 다른 세션 일반화 신뢰구간이나 독립 검증으로 해석하지 않음.
- [x] 주법×1/3옥타브 중심점 근거표 v1 (`guitar_evidence_ledger.py`): 15×89=1,335칸 중 탐색 관측 318칸. 창 길이·유효 창 수·스피커 지원·정렬·앞뒤·정규화 민감도와 미관측을 분리.
- [ ] 검증된 모든 탄현의 정확한 onset/offset·현/음높이 ID. 현재 개방현 강한 19개 사건과 다이내믹 75개 사건은 조건부 분석이고, 약한 탄현·긴 감쇠·앞 음 잔향 전체의 경계는 검수되지 않음. 자동 후보를 확정 라벨로 승격하지 않음.
- [ ] 참 독립 학습/검증/최종 평가 분할. 10월 모든 주법 및 마지막 곡이 탐색에 노출됨. 개방현 세 반복은 같은 패턴 가족이라 분할 시 함께 취급. 9월은 다른 배치·처리 불확실성이 있는 간접 전이 점검만 가능하며, 새 녹음 후 계수 고정 검증 필요.
기존 히트맵·EQ 점수는 10월 탐색 결과이며, 주법·음역·음량·위치의 효과를 인과적으로 분리하지 않는다.

## Phase 4 — 10월 기준 음색 EQ 설계 및 수치 평가 [고정 후보 보존; 참조 기반 정적/시간별 진단 완료]

- [x] 2026-10-11 청취 피드백 **“앞선 후보보다 나아졌으나 아직 밝음”** 반영. 이전 중심 대역 상한 5.08kHz·스펙트로그램 상한 6kHz에서 빠진 6–10kHz를 `brightness_extension.py`로 추가 검사. 주법별 신뢰도는 양쪽 배경 대비 SNR(분자와 400–1600Hz 기준 분모 모두 확인)·대역 적분 에너지 비중으로 계산. 기존 중역 평가에서 선택한 창 모집단을 유지했으므로 전체 기타 커버리지 주장은 하지 않음.
- [x] S21: 신뢰 조건 ≥0.25를 통과한 91/127창 모두 6–10kHz/400–1600Hz 상대 에너지가 KM184보다 강함. 핑크·화이트·로그의 같은 대역 상대 보정은 약 −18.0/−18.1/−17.4dB(300–700Hz 기준)로 같은 방향. 앞선 후보 뒤에 6kHz/S=1/−6dB 인과 하이셸프 한 단 추가. 주법 신뢰 창 중앙값에 근거해 최대 −6dB로 제한; 창별 중앙 상대 과다 +10.984→+6.358dB, 절대 차이 >0.5dB 악화 0/91. 기존 중저역은 추가 최적화하지 않음. 이는 밝기 관련 에너지 지표의 같은 세션 탐색 개선이며 질감 복원의 입증은 아님.
- [x] iPhone: 6–10kHz 신뢰 45/135창 중 과다 1창, 중앙 상대 차이 −8.601dB. 화음의 전체 고역량은 이미 작고, 퍼커션 1.6–3.2kHz 상대 과다는 별도로 남음. 따라서 공통 하이셸프를 적용하지 않음. “밝다”를 총 고역 과다의 원인 진단으로 해석하지 않고 성분 대비·어택·중역 균형 문제는 미확정으로 남김.
- [x] [상위 대역 보완 청취](../../docs/experiments/20261008-iphone-km184-public/brightness-extension.html): 아르페지오 100초·개방현 418초·복합 화음 1704초·퍼커션 1792초를 기준/원본/앞선 후보/S21 하이셸프 후보로 비교. 80Hz–12kHz 스펙트로그램·잔차·6–10kHz 강조·대역별 SNR/상대 과다·같은 시각 재생 제공. S21 연속 전체 녹음 샘플 피크 +2.950dBFS, 4배 오버샘플 근사 +2.955dBFS(출력 감쇠 전), 기존 −6.5dB 출력 게인 유지 시 약 −3.55dBFS. iPhone 고역 감쇠 후보는 만들지 않음.

- [x] 2026-10-11 **스피커 기준×기타 주법별 confidence 중고역 재평가** (`speaker_guitar_confidence_eq.py`, `speaker-guitar-confidence-eq.json`). 같은 10월 스피커의 핑크·화이트 노이즈와 AudioCheck 로그 스윕을 각각 KM184 대비 기기 상대 PSD로 환산하고 300–700Hz 기준으로 레벨을 맞춤. 세 신호 간 퍼짐, 기타 5초 창의 양쪽 배경 대비 SNR, 해당 대역의 폭 포함 에너지 비중, 11주법 지지 수와 보정 방향 일치로 적합 가중치를 정함. 선형 스윕은 전체 구간 PSD에서 세 신호와 큰 불일치가 있어 이번 곡선의 근거에서 제외하고 QC 값만 저장; 원인 확정 아님. 스피커/기타는 서로 다른 위치·방사를 포함하므로 스피커는 직접음 역필터가 아닌 사전 단서로만 사용.
- [x] **S21 탐색 후보:** 기존 저역 세 단을 고정하고 중고역 두 단으로 대체. 1.6kHz/Q0.75/+0.34dB, 4.2kHz/Q0.7/−4.00dB. 주법 동일 가중 0.8–5.08kHz 관측 대역 오차 기존 3.280→2.919dB; 127창 중 0.5dB 초과 악화 6창. 퍼커션은 유효 2창뿐이므로 별도 효과 확정 불가. 같은 세션의 설계 노출 평가로, 청감상 질감 복원을 입증하지 않음.
- [x] **iPhone 후보 보류:** 기존 중역을 스피커 기준으로 대체한 첫 시도는 기존 대비 95/135창 악화. 기존 필터를 고정하고 신뢰 대역 잔차 두 단(1.6kHz/Q0.8/−0.63dB, 3.2kHz/Q0.8/−1.52dB)을 더한 두 번째 시도도 주법 동일 가중 오차 3.275→3.659dB, 66/135창 악화. 따라서 새 후보는 진단용 청취에만 남기고 채택하지 않음. 스피커와 기타의 반대 방향·협소한 지지 구간을 고정 EQ로 억지로 해소하지 않는다.
- [x] [같은 시각의 네 버전 비교](../../docs/experiments/20261008-iphone-km184-public/speaker-guitar-confidence-eq.html): 아르페지오 100초, 개방현 418초, 복합 화음 1704초, 퍼커션 1792초의 KM184·원본·기존·새 후보를 iPhone/S21 각각 같은 위치 재생, 공통 밝기 스펙트로그램·잔차·응답 곡선·주법 점수와 연결. 사용자 청감 확인은 수치상 개선 주장과 분리.
