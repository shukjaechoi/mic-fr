iPhone은 중역 본체 제어, S21은 고역 고정 감쇠와 중역 본체 제어를 분리했습니다. 기존 공통 1/12 EQ를 유지한 채 추가하는 처리입니다. 첫 8타격의 과다 중앙값 절반만 반영하고 최대 4dB로 제한했습니다.

확인된 타격 시점을 사용하는 진단 후보입니다. 입력만으로 자동 검출하는 필터가 아닙니다. 마지막 5타격은 설계에서 제외했지만 이미 탐색한 같은 세션의 개발 평가입니다. 화음·아르페지오에는 KM184 에너지 상승 후보를 사용해 정상 울림의 변화도 확인합니다.

수치상 결과: 마지막 5타격의 중역 본체 과다는 iPhone +7.47→+6.10dB, S21 +4.35→+3.56dB로 줄었습니다. S21 고역 어택은 +7.20→+3.98dB입니다. 반면 화음·아르페지오에 본체 처리를 적용한 평균 오차는 소폭 악화됩니다. 이번 후보는 퍼커션 조건용으로 보며 공통 EQ를 대체하지 않습니다. iPhone 고역 어택의 부족은 여전히 남습니다.

구현과 해석 범위

새 중역 처리에는 85ms STFT 분석창과 60ms 평활화가 없습니다. 40ms까지 기존 경로를 유지하고 30ms 동안 감쇠 경로로 부드럽게 전환, 150–300ms에 복귀합니다. 두 안정된 고정 IIR 경로를 연속 처리한 뒤 혼합하므로 계수를 급변시키지 않습니다. 실제 앞뒤 문맥을 포함했고 후보마다 같은 안전 배율을 적용했습니다. 혼합 응답은 단순 dB 보간과 다르며 위상 복원이나 잔향 제거 모델은 아닙니다. 중역 EQ 경로의 필터 상태는 계속 유지되지만 출력 혼합은 타격 시점에만 작동합니다.

이전 시간별 보정은 같은 클립의 KM184 크기를 참조한 진단용 처리입니다. 새 후보는 8타격에서 강도를 고정하고 알려진 onset만 사용합니다. 둘의 정보 사용 범위가 다릅니다. 새 처리의 방향이 유효하면 다음 단계는 기기 입력 검출로 교체해 검출 오류와 출력 품질을 평가하는 것입니다. 입력 검출 전에는 실시간 사용 완료라고 부르지 않습니다.
